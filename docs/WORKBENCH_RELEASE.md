## 发布重现性说明

容器环境报告逐文件验证实际安装的 Python 模块与工作区一致，并保存镜像 ID 与依赖版本。
文档在宿主机和阶段归档中更新；现有镜像内 README 是构建时快照，不作为最新使用说明。
Dockerfile 中部分依赖是版本范围，未来重新联网构建可能解析到新版本，应按相同脚本重做验收；
不能把一次通过自动推广到未来镜像。该镜像为本机 CPU 验证，不承诺其他架构/硬件相同性能。
