# GitHub 发布说明

本仓库发布 AudioScope v1.0.0 的源码、配置、数据库迁移、测试、模型卡、实验报告和可复核的
软件验证摘要。它适合代码审阅、作品集展示和从源码复现实验。

## 仓库包含什么

- `src/audioscope/`：分类、事件检测、长音频、流式推理、工作台、API 与发布验证代码；
- `configs/`：L1–L4 与软件验证使用的固定配置；
- `tests/`：算法、数据、API、工作台和有界流式状态回归测试；
- `migrations/`：PostgreSQL/Alembic 数据模型迁移；
- `docs/`、`reports/`：使用说明、模型卡、实验协议、结果与限制；
- `release-evidence/`：适合公开复核的小型机器可读验证结果。

## 为什么不提交数据和权重

第三方音频受各自许可和来源条款约束；预训练模型可从原发布方按固定 revision 获取；训练输出、
特征缓存和本地数据库可由脚本重建。因此 Git 忽略以下内容：

- 原始、重采样和混合音频；
- DESED/ESC-50 下载内容与特征缓存；
- CLAP/AST 预训练权重与训练 checkpoint；
- `.env`、PostgreSQL 数据卷、用户上传和复核历史；
- 视频构建中间文件及本机桌面启动器。

具体数据版本、许可、revision 与权重 SHA-256 记录在 `data/sources.yaml`。发布证据中的模型哈希
可用于核对本地资产，但不能替代相应来源的许可。

## 复现层级

1. `pip install -e '.[dev]'` 后可运行不依赖大型外部资产的基础测试与 smoke 流程。
2. 安装相应 optional dependency 并准备 `data/sources.yaml` 登记的数据，可复现 L1–L3 实验。
3. 准备本地模型与 `.env` 后，可运行 L4 工作台、数据库和 Docker 服务。
4. `software-final` 证明软件验证完成；`field-final` 仍会如实显示物理设备/房间认证未完成。

不得把可控软件域偏移写成真实设备或真实房间测试，也不得把外部素材回听写成自有实体麦克风
验收。
