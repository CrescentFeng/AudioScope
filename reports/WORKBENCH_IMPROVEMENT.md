# 工作台增强：识别质量、可控鲁棒性与可复核检索

2026-10-11。原 v1.0 封板不修改。这里记录后续增强实验，不宣称物理设备/房间认证。

## 训练与选择协议

DESED 强标注录音按原源录音隔离划分：703 train / 229 validation / 221 test。
三种种子 2027/2028/2029 成对训练基线与“稀有类别加权采样＋软件域偏移增强”。
训练只使用 train；阈值、解码和平衡增强取舍只使用 validation；测试前冻结方案和模型哈希。
这一 test 划分已经用于先前报告，不是全新盲测，也不是 DCASE 官方协议。

增强训练的多条件验证目标均值略有提高，但干净条件下降超过预设容忍值，因此没有替换默认权重。
负面实验与三种子全部结果保留在 `reports/generated/model-improvement/development_summary.json`。

另一个实验保留 v1.0 权重与 ONNX，只在验证集选择中值平滑、合并间隔和最短事件时长。
选中 overall 阈值 0.8、中值 5 帧、间隔 0.2 秒、最短 0.12 秒；其他类别工作点也仅用验证集选择。
完整网格见 `decoder_selection.json`，默认模型登记于 `artifacts/workbench-release/model_registry.json`。

## 冻结后的测试结果

221 条录音 × 七条件，固定软件扰动种子 2027。下表为 micro event-F1：

| 条件 | v1.0 | 边界优化版 |
|---|---:|---:|
| clean | 0.2583 | 0.2873 |
| 短混响 | 0.2531 | 0.2802 |
| 长混响 | 0.2436 | 0.2730 |
| 电话带宽 | 0.1953 | 0.2474 |
| 笔记本响应模拟 | 0.2303 | 0.2662 |
| 10 dB 粉红噪声 | 0.2165 | 0.2493 |
| 复合扰动 | 0.1871 | 0.2244 |

六种扰动的均值 0.2210 → 0.2568，clean 短事件 F1 0.1802 → 0.2257。
但 clean 精确率 0.1924 → 0.2372 的同时，召回率 0.3925 → 0.3642：
误报 1,280 → 910，漏报 472 → 494。不能表述为“全面提高”或“识别准确率 28.7%”。
clean macro event-F1 0.1865 → 0.2095，仍有明显逐类不均衡。

逐类、时长分层、软件条件及误差分类在 `heldout_summary.json` 和 `heldout/` 下保存。
错误分类是匹配/重叠规则产生的诊断线索，不是人工确认的声学根因。
软件模拟带宽和混响不对应特定真实麦克风或真实房间。

## 性能与内存回归

候选使用同一处理器加速输入 1,800 秒音频，不是经过 30 分钟墙钟时间的硬件验收。
本机结果：RTF 0.002490、1 秒输入块计算 P95 2.786 ms、预热后 RSS 增长约 9.59 MiB。
有界状态、无重复事件、每类事件时间顺序及重复输入哈希全部通过。
时间依赖主机和负载，不承诺容器或其他硬件相同表现。

## 方向 A：可回听、可复核的工作台

原始预测不覆盖；复核追加版本、有显式确认和冲突保护；模型哈希与阈值记录随任务保留。
支持排序后的事件行回听、预测/参考双时间轴、同音频模型对照、历史重开、哈希重新关联和导出。
这些能力用于核验和整理，不保证人工复核本身无误，不自动授权训练。

## 方向 B：文字与重叠检索

已知类别查询是对预测的筛选/区间交集；CLAP 是对本地音频的英文语义相似排序。
固定十类英文查询在全部 221 条测试录音构成的序列上评估：120 次查询，97 次有参考阳性窗口，
23 次没有对应声音。有阳性查询的平均 P@5=0.6598、Recall@10=0.6419、MRR@10=0.8926；
随机窗口期望阳性比例为 0.2536。这些数值不是通用声音识别准确率。

当前无拒答阈值，23 次目标缺失查询仍会返回候选；不支持中文开放描述。
10 秒候选窗口可重叠，不能用其边界代替精确事件起止。详见 `workbench/retrieval_evaluation.json`。
